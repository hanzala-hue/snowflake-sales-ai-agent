# 🤖 Sales Intelligence AI Agent

An AI-powered Sales Intelligence Agent built using Snowflake Cortex Agents.

Created by **Md Hanzala**.

## 📌 Project Overview

This project is an AI agent designed to analyze sales data and answer business-related questions using natural language.

The agent can help users understand sales performance, customers, products, win rates, and other available sales metrics.

## 🚀 Features

- Natural-language interaction
- Sales data analysis
- Sales performance analysis
- Product-line analysis
- Customer analysis
- Win-rate analysis
- Sales representative analysis
- Structured sales data analysis
- Sales conversation insights
- Python code execution for analysis
- Personalized AI-agent responses

## 🧠 Technologies Used

- Snowflake
- Snowflake Cortex Agents
- Cortex Analyst
- Cortex Search
- SQL
- Python
- Generative AI
- Data Analytics

## 🏗️ Architecture

## 💬 Example Questions

- What is our total sales?
- What is our win rate by product line?
- Who are our top customers?
- Which sales representative has the highest sales?
- What are the main concerns mentioned by customers?
- Show sales performance by product line.
- What is the average deal size?
